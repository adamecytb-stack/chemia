# Chémia – prvky a periodická tabuľka

Učebná appka z chémie (9. ročník): https://adamecytb-stack.github.io/chemia/

- 7 tém: najprv výklad, hneď po ňom skúška z témy
- úlohy na vzorce a chemické rovnice (dopĺňanie aj celá rovnica) s postupom v riešení
- veľký test na známku zo všetkých tém
- ťahák so značkami, vzorcami, rovnicami a pojmami
- funguje na mobile, po prvom otvorení aj bez internetu; dá sa pridať na plochu

Obsah je zo školského zošita. Bloky označené „nie je v zošite“ sú dovysvetlenie navyše.

Všetko je v jednom súbore `index.html`, bez knižníc a bez buildu.
